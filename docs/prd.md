# 需求文档

## 1. 应用概述

### 1.1 应用名称
ai音乐音频处理Pro

### 1.2 应用描述
面向音乐发烧友和专业音频工程师的专业音频处理工具，支持多格式音频转换、发烧级母带制作标准品质提升、AI音质提升、Stem分离、加密格式解密、曲谱制作、万能音乐播放器、参数调节、动态处理、AI智能调参、批处理、分析工具、元数据编辑等功能，提供波形与频谱可视化分析能力，帮助用户实现高质量音频转换与管理。无需登录即可使用所有功能。

### 1.3 目标平台
iOS、Android

### 1.4 UI设计风格
- 主背景色：深蓝 #0A1128（工程蓝图风格）
- 强调色：橙色 #FF5E00
- 荧光青：#00F0FF
- 字体：等宽字体（monospace / JetBrains Mono）
- 风格：工程蓝图、科技感、深色主题

## 2. 用户与使用场景

### 2.1 目标用户
音乐发烧友、专业音频工程师、对音质有较高要求的用户

### 2.2 核心使用场景
- 将不同格式的音频文件转换为所需格式
- 以母带制作标准提升低码率音频品质
- 使用AI技术对音频进行降噪、超分修复、响度标准化等音质提升处理
- 从混音音乐中分离人声、鼓、贝斯、其他乐器等音轨
- 解锁并转换平台加密格式文件
- 基于音频自动生成曲谱
- 播放所有格式音乐文件并查看波形/频谱可视化
- 批量处理多个音频文件
- 通过波形和频谱分析评估转换质量
- 实时调节音频参数并预览效果
- 使用AI智能推荐最优参数组合
- 使用预设快速批量处理音频
- 分析音频响度与削波情况
- 编辑音频元数据信息

## 4. 业务规则与逻辑

### 4.1 格式转换规则
- 支持的格式互转关系：MP3、FLAC、WAV、AAC、OGG、ALAC、APE、DSD、MQA之间可任意互转
- 有损格式转无损格式时，提示用户「转换不会真正提升音质，仅改变封装格式」
- 格式转换基于原生ffmpeg-kit实现

### 4.2 发烧级母带制作标准品质提升规则
- 低码率音频升级为高码率/无损格式
- 音频增强处理包含降噪、动态范围优化等算法
- 确保转换过程不降低原始音质
- 提升后文件大小显著增加

### 4.3 AI音质提升规则

#### 4.3.1 简单模式规则
- 通过WebView加载本地HTML页面，页面内使用ffmpeg.wasm（@ffmpeg/ffmpeg + @ffmpeg/util）进行音频处理
- App端通过expo-file-system读取本地音频文件为Base64，通过WebView的postMessage/onMessage机制传递给内嵌页面
- 内嵌页面处理完成后，将结果音频Base64回传给App，App写回本地文件
- 支持的处理算法：
  - 降噪：afftdn或arnndn
  - 超分修复：高质量重采样+crystalizer
  - 响度标准化：loudnorm
- 大文件处理：通过分片传输或限制时长处理Base64传输的性能与内存问题
- 零付费、零账号、完全开源，不使用任何需要实名注册/绑定信用卡/按次收费的商业API
- 不依赖onnx runtime原生模块

#### 4.3.2 困难模式规则

##### 4.3.2.1 本地优先处理
- 降噪、超分、均衡、增益等核心处理优先使用本地FFmpeg + ONNX Runtime
- 不依赖外网即可完成基础增强
- 本地处理完成后自动保存至本地存储

##### 4.3.2.2 云端增强（可选）
- 在设置页面中提供「云端增强」开关，默认关闭
- 用户手动开启后，在本地处理完成后自动调用外网开源AI接口对结果进行二次优化（如音质美化、高频修复）
- 云端增强仅上传本地处理后的临时音频文件，不上传原始文件
- 处理完成后自动删除云端临时文件

##### 4.3.2.3 云端接口选择与容错
- 预置6个开源AI音频增强接口（至少3个可用，可后续替换）
- 所有外部请求通过Edge Function代理转发
- 接口选择策略：
  - 正式处理前先用3秒探针逐个探测接口
  - 择首个返回200的接口执行正式请求
  - 正式请求使用AbortController设置25秒超时
  - 超时或失败自动切换到备用接口
  - 全部接口不可用时弹出「繁忙」提示，本地处理结果仍保留

##### 4.3.2.4 交互反馈
- 使用云端增强时，界面显示「云端增强中... 预计X秒」
- 处理完成提示「本地处理完成，已额外应用云端增强」
- 云端增强失败时提示「本地处理完成，云端增强失败」，本地处理结果仍保留

### 4.4 参数设置规则
- 采样率、位深、码率的可选值根据目标格式动态调整
- 有损格式（MP3、AAC、OGG）不支持位深设置
- 无损格式（FLAC、WAV、ALAC、APE）不支持码率设置
- 母带级格式（DSD、MQA）支持特定采样率与位深组合

### 4.5 Stem分离规则
- 支持从混音音乐中分离人声、鼓、贝斯、其他乐器等音轨
- 用户可选择分离一个或多个音轨
- 每个Stem独立导出为音频文件

### 4.6 加密格式解密规则
- 自动识别平台加密格式（NCM、QMC等）
- 一键解密并转换为用户指定的目标格式
- 解密过程保留原始音质

### 4.7 曲谱制作规则
- 基于音频文件自动生成曲谱
- 支持吉他谱、钢琴谱类型
- 生成的曲谱可导出为PDF或图片格式

### 4.8 播放器规则
- 支持播放所有主流格式音频文件
- 实时展示波形/频谱可视化
- 支持播放控制、进度调节、音量控制、循环模式切换
- 播放列表按导入顺序或用户自定义顺序排列

### 4.9 批量转换规则
- 批量转换时所有文件使用相同的目标格式与参数
- 单个文件转换失败不影响其他文件继续转换
- 批量转换完成后统一展示成功与失败数量

### 4.10 文件导入导出规则
- 导入时自动识别音频文件格式
- 导出时文件保存至手机本地存储的指定目录
- 历史记录保留最近100条转换任务

### 4.11 录音规则
- 支持后台录制母带级音频
- 录音文件自动保存至文件管理列表

### 4.12 自动化处理规则
- 功能操作自动化，减少手动步骤
- 转换、分离、解密、曲谱生成、AI音质提升等任务自动完成处理

### 4.13 参数调节规则
- 所有参数默认关闭
- 实时预览开关启用时，参数调节实时生效并预览效果
- 实时预览开关关闭时，参数调节不实时生效，需点击「应用处理」后执行
- 降噪强度范围0-100%，默认值0%
- 混音比例 Dry/Wet 调节原始信号与处理信号混合比例
- 增益补偿范围-12dB ~ +12dB，默认值0dB
- 6段EQ每段范围±12dB，默认值0dB
- LUFS标准化目标为-14 LUFS
- 压缩器、限幅器为开关按钮，默认关闭
- 全部基于FFmpeg + ONNX本地运行，无需联网

### 4.14 AI智能调参规则
- AI自动分析音频内容类型（人声/音乐/混合）
- 根据内容类型推荐最优参数组合（含降噪强度、EQ、增益、压缩）
- 用户可一键应用推荐参数
- 用户可在推荐参数基础上手动微调
- 全部基于FFmpeg + ONNX本地运行，无需联网

### 4.15 批处理规则
- 支持多文件队列批量转换
- 预设包含「人声优化」「古典修复」「直播清晰」
- 用户可保存自定义预设
- 批处理时所有文件使用相同的预设参数
- 单个文件处理失败不影响其他文件继续处理
- 批处理完成后统一展示成功与失败数量

### 4.16 分析工具规则
- 响度历史曲线展示音频响度随时间变化
- 削波标记标记音频中存在削波的位置
- A/B对比同时展示原始音频与处理后音频的波形、频谱、响度曲线

### 4.17 元数据编辑规则
- 支持编辑音频标题、艺术家、专辑信息
- 采样率算法可选择FFmpeg或SoX
- 元数据修改保存后立即生效

### 4.18 云端增强设置规则
- 云端增强开关默认关闭
- 用户可在设置页面手动开启
- 开启后仅在困难模式AI音质提升中生效
- 云端增强仅上传本地处理后的临时音频文件，不上传原始文件
- 处理完成后自动删除云端临时文件

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 导入的文件格式不支持 | 提示「不支持的音频格式」，不允许导入 |
| 转换过程中发生错误 | 提示「转换失败，请重试」，保留源文件 |
| 存储空间不足 | 提示「存储空间不足，请清理后重试」，终止转换 |
| 参数设置超出合理范围 | 自动调整至最接近的合法值 |
| 批量转换中部分文件失败 | 继续转换其他文件，完成后列出失败文件清单 |
| 波形/频谱分析加载失败 | 提示「分析数据加载失败」，允许重新加载 |
| Stem分离失败 | 提示「分离失败，请重试」，保留源文件 |
| 加密格式无法识别 | 提示「无法识别的加密格式」，不允许解密 |
| 加密格式解密失败 | 提示「解密失败，请重试」，保留源文件 |
| 曲谱生成失败 | 提示「曲谱生成失败，请重试」 |
| 播放器加载文件失败 | 提示「文件加载失败」，跳过该文件播放下一曲 |
| AI音质提升简单模式处理失败 | 提示「处理失败，请重试」，保留源文件 |
| AI音质提升困难模式本地处理失败 | 提示「本地处理失败，请重试」，保留源文件 |
| AI音质提升困难模式云端增强接口探测全部失败 | 弹出「繁忙」提示，本地处理结果仍保留 |
| AI音质提升困难模式云端增强正式请求超时或失败 | 自动切换到备用接口，全部接口不可用时弹出「繁忙」提示，本地处理结果仍保留 |
| AI音质提升困难模式云端增强失败 | 提示「本地处理完成，云端增强失败」，本地处理结果仍保留 |
| WebView加载失败 | 提示「页面加载失败」，允许重新加载 |
| Base64传输超时或内存溢出 | 提示「文件过大或处理超时」，建议缩短音频时长或分段处理 |
| 参数调节实时预览失败 | 提示「预览失败」，关闭实时预览开关 |
| AI智能调参分析失败 | 提示「分析失败，请重试」 |
| 批处理队列为空 | 提示「请先添加文件至队列」 |
| 批处理中部分文件失败 | 继续处理其他文件，完成后列出失败文件清单 |
| 分析工具加载失败 | 提示「分析数据加载失败」，允许重新加载 |
| 元数据编辑保存失败 | 提示「保存失败，请重试」 |
| 云端增强开关开启但网络不可用 | 提示「网络不可用，仅使用本地处理」，本地处理结果仍保留 |

## 6. 验收标准

1. 用户打开App，进入文件管理页面，使用录音功能录制一段音频
2. 用户进入工具箱，点击「AI音质提升」入口
3. 用户在AI音质提升页面切换至「困难模式」，选择刚录制的音频文件
4. 用户进入设置页面，开启「云端增强」开关
5. 用户返回AI音质提升页面，点击「开始处理」
6. 系统先执行本地FFmpeg + ONNX处理，完成后自动调用外网开源AI接口进行云端增强
7. 处理完成后弹出提示「本地处理完成，已额外应用云端增强」，用户点击「立即试听」
8. 用户进入播放器，播放处理后的音频文件，查看波形/频谱可视化
