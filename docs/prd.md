# 需求文档

## 1. 应用概述

### 1.1 应用名称
音乐格式转换器

### 1.2 应用描述
面向音乐发烧友和专业音频工程师的专业音频格式转换工具，支持多格式音频转换、发烧级母带制作标准品质提升、AI音质提升、Stem分离、加密格式解密、曲谱制作、万能音乐播放器等功能，提供波形与频谱可视化分析能力，帮助用户实现高质量音频转换与管理。无需登录即可使用所有功能。

### 1.3 目标平台
iOS、Android

### 1.4 UI设计风格
- 主背景色：深蓝 #0A1128（工程蓝图风格）
- 强调色：橙色 #FF5E00
- 荧光青：#00F0FF
- 字体：等宽字体（monospace / JetBrains Mono）
- 风格：工程蓝图、科技感、深色主题

## 2. 用户与使用场景

### 2.1 目标用户
音乐发烧友、专业音频工程师、对音质有较高要求的用户

### 2.2 核心使用场景
- 将不同格式的音频文件转换为所需格式
- 以母带制作标准提升低码率音频品质
- 使用AI技术对音频进行降噪、超分修复、响度标准化等音质提升处理
- 从混音音乐中分离人声、鼓、贝斯、其他乐器等音轨
- 解锁并转换平台加密格式文件
- 基于音频自动生成曲谱
- 播放所有格式音乐文件并查看波形/频谱可视化
- 批量处理多个音频文件
- 通过波形和频谱分析评估转换质量

## 3. 页面结构与功能说明

### 3.1 页面结构

```
底部Tab导航（4个Tab）
├── 转换（首页）
├── 文件管理
├── 播放器
└── 工具箱
    ├── Stem分离页面
    ├── 加密解密页面
    ├── 曲谱制作页面
    ├── AI音质提升页面
    └── 预览分析页面

独立页面
├── 参数设置页面
└── 各功能详情页面
```

### 3.2 功能说明

#### 3.2.1 转换（首页）
- 文件选择：从文件管理中选择待转换的音频文件
- 格式选择：选择目标格式（MP3、FLAC、WAV、AAC、OGG、ALAC、APE、DSD、MQA等）
- 转换模式选择：
  - 格式转换：不同格式间互转
  - 发烧级母带制作标准品质提升：低码率音频升级为高码率/无损格式，包含音频增强处理（降噪、动态范围优化）
- 参数设置入口：跳转至参数设置页面
- 开始转换：执行转换任务（支持单文件转换和批量转换）
- 转换进度显示：实时显示当前转换进度
- 转换完成后提供预览分析入口

#### 3.2.2 文件管理
- 导入文件：从手机本地存储导入音频文件
- 录音功能：后台录制母带级音频
- 文件列表：展示已导入的音频文件，包含文件名、格式、大小、时长信息
- 文件操作：删除、重命名、导出至本地存储
- 历史记录：展示已完成的转换任务记录，包含源文件、目标格式、转换时间

#### 3.2.3 播放器
- 播放控制：播放、暂停、上一曲、下一曲
- 进度条：显示当前播放进度，支持拖拽跳转
- 波形/频谱可视化：实时展示当前播放音频的波形与频谱
- 播放列表管理：展示当前播放队列，支持添加、删除、排序
- 循环模式：单曲循环、列表循环、随机播放
- 音量控制：调整播放音量
- 支持格式：播放所有主流格式音频文件（MP3、FLAC、WAV、AAC、OGG、ALAC、APE、DSD、MQA等）

#### 3.2.4 工具箱
- Stem分离入口：跳转至Stem分离页面
- 加密解密入口：跳转至加密解密页面
- 曲谱制作入口：跳转至曲谱制作页面
- AI音质提升入口：跳转至AI音质提升页面
- 预览分析入口：跳转至预览分析页面

#### 3.2.5 参数设置页面
- 采样率设置：可选44.1kHz、48kHz、96kHz、192kHz等
- 位深设置：可选16bit、24bit、32bit
- 码率设置：可选128kbps、192kbps、256kbps、320kbps或自定义
- 音频增强开关：启用/关闭音频增强处理
- 保存设置：应用当前参数配置

#### 3.2.6 预览分析页面
- 波形展示：以波形图形式展示音频文件的振幅变化
- 频谱分析：以频谱图形式展示音频文件的频率分布
- 对比模式：同时展示转换前后的波形与频谱，便于质量对比

#### 3.2.7 Stem分离页面
- 选择源文件：从文件管理中选择待分离的音频文件
- 分离选项：人声、鼓、贝斯、其他乐器
- 开始分离：执行Stem分离任务
- 进度显示：实时显示当前分离进度
- 结果预览：分离完成后展示各音轨文件列表
- 导出音轨：将分离后的音轨独立导出至本地存储

#### 3.2.8 加密解密页面
- 选择加密文件：从文件管理中选择加密格式音频文件
- 自动识别：自动识别加密类型（NCM、QMC等平台加密格式）
- 选择目标格式：选择解密后的输出格式
- 一键解密：执行解密与转换任务
- 进度显示：实时显示当前解密进度
- 解密完成后提供预览分析入口

#### 3.2.9 曲谱制作页面
- 选择源文件：从文件管理中选择待生成曲谱的音频文件
- 曲谱类型选择：吉他谱、钢琴谱
- 开始生成：执行曲谱生成任务
- 进度显示：实时显示当前生成进度
- 谱面预览：展示生成的曲谱
- 导出曲谱：将曲谱导出为PDF或图片格式

#### 3.2.10 AI音质提升页面
- 模式切换：顶部提供「简单模式」和「困难模式」切换入口
  - 简单模式图标：闪电/火箭
  - 困难模式图标：云端/大脑
- 选择源文件：从文件管理中选择待处理的音频文件（支持录音后的音频或已导入的音频文件）
- 简单模式：
  - 处理选项：降噪处理、超分修复、响度标准化
  - 说明文案：使用本地DSP引擎，离线、免费、开源
- 困难模式：
  - 处理选项：AI增强
  - 说明文案：使用外网开源AI接口，依赖网络与云端AI算力，文件大小限制20MB或时长限制3分钟
- 开始处理：执行AI音质提升任务
- 进度显示：实时显示当前处理进度
- 处理完成后弹出成功提示框，提供「立即试听」按钮
- 处理后的文件自动保存至本地存储并列入文件管理列表

## 4. 业务规则与逻辑

### 4.1 格式转换规则
- 支持的格式互转关系：MP3、FLAC、WAV、AAC、OGG、ALAC、APE、DSD、MQA之间可任意互转
- 有损格式转无损格式时，提示用户「转换不会真正提升音质，仅改变封装格式」
- 格式转换基于原生ffmpeg-kit实现

### 4.2 发烧级母带制作标准品质提升规则
- 低码率音频升级为高码率/无损格式
- 音频增强处理包含降噪、动态范围优化等算法
- 确保转换过程不降低原始音质
- 提升后文件大小显著增加

### 4.3 AI音质提升规则

#### 4.3.1 简单模式规则
- 通过WebView加载本地HTML页面，页面内使用ffmpeg.wasm（@ffmpeg/ffmpeg + @ffmpeg/util）进行音频处理
- App端通过expo-file-system读取本地音频文件为Base64，通过WebView的postMessage/onMessage机制传递给内嵌页面
- 内嵌页面处理完成后，将结果音频Base64回传给App，App写回本地文件
- 支持的处理算法：
  - 降噪：afftdn或arnndn
  - 超分修复：高质量重采样+crystalizer
  - 响度标准化：loudnorm
- 大文件处理：通过分片传输或限制时长处理Base64传输的性能与内存问题
- 零付费、零账号、完全开源，不使用任何需要实名注册/绑定信用卡/按次收费的商业API
- 不依赖onnx runtime原生模块

#### 4.3.2 困难模式规则
- 使用外网开源AI接口进行音频增强
- 预置6个开源AI音频增强接口（至少3个可用，可后续替换）
- 所有外部请求通过Edge Function代理转发
- 接口选择策略：
  - 正式处理前先用3秒探针逐个探测接口
  - 择首个返回200的接口执行正式请求
  - 正式请求使用AbortController设置25秒超时
  - 超时或失败自动切换到备用接口
  - 全部接口不可用时弹出「繁忙」提示并提供「切简单模式」按钮
- 预检逻辑：
  - 请求前判断文件大小是否大于20MB或时长是否大于3分钟
  - 达标则拦截并弹出「文件过大」提示，建议导出/截短后重试
- 完成流程：
  - 处理完毕后静默保存到本地存储
  - 弹出成功提示框并提供「立即试听」按钮
  - 将处理后的文件列入文件管理列表

### 4.4 参数设置规则
- 采样率、位深、码率的可选值根据目标格式动态调整
- 有损格式（MP3、AAC、OGG）不支持位深设置
- 无损格式（FLAC、WAV、ALAC、APE）不支持码率设置
- 母带级格式（DSD、MQA）支持特定采样率与位深组合

### 4.5 Stem分离规则
- 支持从混音音乐中分离人声、鼓、贝斯、其他乐器等音轨
- 用户可选择分离一个或多个音轨
- 每个Stem独立导出为音频文件

### 4.6 加密格式解密规则
- 自动识别平台加密格式（NCM、QMC等）
- 一键解密并转换为用户指定的目标格式
- 解密过程保留原始音质

### 4.7 曲谱制作规则
- 基于音频文件自动生成曲谱
- 支持吉他谱、钢琴谱类型
- 生成的曲谱可导出为PDF或图片格式

### 4.8 播放器规则
- 支持播放所有主流格式音频文件
- 实时展示波形/频谱可视化
- 支持播放控制、进度调节、音量控制、循环模式切换
- 播放列表按导入顺序或用户自定义顺序排列

### 4.9 批量转换规则
- 批量转换时所有文件使用相同的目标格式与参数
- 单个文件转换失败不影响其他文件继续转换
- 批量转换完成后统一展示成功与失败数量

### 4.10 文件导入导出规则
- 导入时自动识别音频文件格式
- 导出时文件保存至手机本地存储的指定目录
- 历史记录保留最近100条转换任务

### 4.11 录音规则
- 支持后台录制母带级音频
- 录音文件自动保存至文件管理列表

### 4.12 自动化处理规则
- 功能操作自动化，减少手动步骤
- 转换、分离、解密、曲谱生成、AI音质提升等任务自动完成处理

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 导入的文件格式不支持 | 提示「不支持的音频格式」，不允许导入 |
| 转换过程中发生错误 | 提示「转换失败，请重试」，保留源文件 |
| 存储空间不足 | 提示「存储空间不足，请清理后重试」，终止转换 |
| 参数设置超出合理范围 | 自动调整至最接近的合法值 |
| 批量转换中部分文件失败 | 继续转换其他文件，完成后列出失败文件清单 |
| 波形/频谱分析加载失败 | 提示「分析数据加载失败」，允许重新加载 |
| Stem分离失败 | 提示「分离失败，请重试」，保留源文件 |
| 加密格式无法识别 | 提示「无法识别的加密格式」，不允许解密 |
| 加密格式解密失败 | 提示「解密失败，请重试」，保留源文件 |
| 曲谱生成失败 | 提示「曲谱生成失败，请重试」 |
| 播放器加载文件失败 | 提示「文件加载失败」，跳过该文件播放下一曲 |
| AI音质提升简单模式处理失败 | 提示「处理失败，请重试」，保留源文件 |
| AI音质提升困难模式文件大小超过20MB或时长超过3分钟 | 拦截并弹出「文件过大」提示，建议导出/截短后重试 |
| AI音质提升困难模式接口探测全部失败 | 弹出「繁忙」提示并提供「切简单模式」按钮 |
| AI音质提升困难模式正式请求超时或失败 | 自动切换到备用接口，全部接口不可用时弹出「繁忙」提示并提供「切简单模式」按钮 |
| WebView加载失败 | 提示「页面加载失败」，允许重新加载 |
| Base64传输超时或内存溢出 | 提示「文件过大或处理超时」，建议缩短音频时长或分段处理 |

## 6. 验收标准

1. 用户打开App，进入文件管理页面，使用录音功能录制一段音频
2. 用户进入工具箱，点击「AI音质提升」入口
3. 用户在AI音质提升页面顶部切换至「困难模式」
4. 用户选择刚录制的音频文件，点击「开始处理」
5. 系统自动探测接口并执行AI增强处理，等待处理完成
6. 处理完成后弹出成功提示框，用户点击「立即试听」按钮
7. 播放器自动播放处理后的音频文件，用户查看波形/频谱可视化
